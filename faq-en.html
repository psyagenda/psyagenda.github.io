Frequently Asked Questions

Common questions and answers about PsyAgenda.

Where is my data stored?

All your data is stored locally on your device (phone, tablet, or computer) only. Data is never sent to any external server. If sync is enabled, data is uploaded encrypted to your Google Drive account.

Can I use it without an internet connection?

Yes. The app works fully offline. Internet is only required for synchronization, AI analysis, and email notifications.

Is my data secure?

Yes. Data is stored locally on your device and is not sent anywhere. If you use sync, data is protected with AES-256 encryption. Backup files are encrypted with the same standard. You can also set an app lock for additional security.

Can I use it on multiple devices?

Yes. Enable Google Drive synchronization to sync your data across devices. All data is transferred encrypted.

I forgot my sync password, what can I do?

The sync password is stored only on your device; no one, including the developer, can access it. If forgotten, you can remove the existing sync connection and set up a new one with a new password. However, encrypted data on other devices cannot be read without the old password.

What data is shared when using AI features?

When AI features are used, only the relevant session notes, test data, or drawing images are sent to the Google Gemini API. Client names, contact information, or financial data are never shared. See the info icon in Settings > API Management for details.

I forgot my app password, what can I do?

Tap "Forgot Password" on the lock screen. You can set a new password by correctly answering the security question you set during setup. If you don't remember the security question either, there is an option to delete all data.

How does backup and restore work?

From Settings > Backup, you can export your data as an encrypted .thnbak file. To restore, select the file from the same section and enter its password. If you forget the backup password, you cannot access that backup.

How can I send notification messages to my clients?

In the appointment modal (by tapping an appointment), use the notification and reminder buttons. WhatsApp, SMS, and email channels are supported. Customize message templates from Settings > Notifications.

What platforms does the app support?

PsyAgenda works on Android, iOS (iPhone, iPad), macOS, and Windows (desktop). All platforms offer the same features.
