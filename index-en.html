PsyAgenda

Smart Therapist Agenda. Ease your life.

PsyAgenda is an agenda application that digitizes the workflow of psychologists, psychiatrists, and counselors end-to-end. Client records, the appointment calendar, session notes, administered psychological tests, and income and expense tracking are all brought together in one place. The application is built on a serverless architecture; all records are stored only on the user's own device, encrypted.

iPhone iPad Android Mac Windows

PsyAgenda is being readied for publication. The download links on this page will become active as the app is published in each store. The application will offer exactly the same interface on iPhone, iPad, Mac, Android, and Windows, and will be distributed solely through the Apple App Store, Google Play, and the Microsoft Store.

Features

No servers

The application has no central server; once installed, by default it runs entirely locally, on the user’s device alone. There is no need to create an account or register; at first launch only the language, an app password, and a security question to be used if that password is forgotten are set. All data entered into the application is stored solely on the user’s own device, in an encrypted database; no record is sent to any server. No one apart from the user — not even the developer — can access this database. There is no central pool of data that could be exposed in a mass breach, and no service outage can stand between the user and their own records. Day-to-day use requires no internet connection; keeping records, searching, and reporting all work offline. The application contains no ads, no analytics, and no user tracking. The user can permanently and completely delete all data entered into the application at any time.

Encrypted at every stage

Data is encrypted not only at rest but also in motion. Client records, session notes, and financial data are held on the device in a database encrypted with AES-256; session and test images sit outside that database as separate files encrypted to the same strength. The key is kept in the operating system’s secure key store and protected by the app password. The application is locked with a password and biometric verification; automatic lock takes effect once the configured idle period elapses. When synchronization is enabled, data is encrypted with a separate password of the user’s choosing before it leaves the device; Drive sees only the encrypted block, and the receiving device decrypts it on the device itself. Backup files are always encrypted. At no point along the storage, synchronization, or backup paths does the data sit unencrypted.

Optional synchronization

The application can be installed on more than one device, and synchronization between them can be enabled if desired; the feature is off by default. The session notes of an appointment created on an iPhone can be written on an iPad or an Android tablet. Synchronization runs without any intermediary server, through the app-private area of the user’s own Google Drive account; that area is not visible in the Drive interface. Google Drive holds only the encrypted data and cannot access the content. Changes made on different devices are merged record by record, without one overwriting the other. All data stored in Drive can be permanently deleted at any time.

The home screen and the day’s flow

When the application is opened, the whole day is visible on a single screen. The day’s sessions are listed in order with their times, each with its note on its own row; hours marked as busy appear in the same flow. Finished sessions can be hidden with a single tap so that the remaining appointments stand out. If a client has an overdue payment, the warning appears in the same list with the amount, so there is no need to open the budget screen. Another day can be viewed without opening the calendar, and a single tap returns to today. The calendar, clients, budget, and test module are also reached from this screen; the top area holds the practice name along with synchronization status and settings.

Calendar and appointments

Provides a highly flexible, dynamic calendar that can be personalized to fit the way you work. Alongside 1, 3, 5, and 7-day views, a monthly view is available. The time grid can be set to 15, 30, or 60 minutes; working hours and the break interval can be defined to match the user’s own schedule. An appointment record can hold the client, duration, session fee, payment status, recurrence pattern, session notes, and image attachments. Beyond sessions, any hour or day can be marked as busy. Recurring sessions can be created as a series, appointments can be moved by drag-and-drop, and no record can be created on a conflicting time slot.

Notifications and reminders

Notifications serve two separate purposes: the therapist's own reminder and the message to be sent to the client. A notification arrives on the phone before a session, and how far in advance it arrives can be set. Alarm-style reminders that keep sounding until silenced can be enabled, and you can decide whether they apply to every session or only to selected ones. On the lock screen, the client's name can be hidden from the notification. Templates for the information and reminder messages sent to clients can be customized; the application does not send the message itself — it opens WhatsApp, SMS, or email on the device with the text ready, and sending is completed with the user's approval. Notifications and alarms work on phones and tablets.

Client management

Provides a record structure where everything about a client is gathered on a single card and can be traced back over time. A card can hold contact and demographic details alongside education and occupation information, a per-client session fee, and notes. There is no limit on the number of clients; records can be separated into active and passive, and the list can be searched by name. Session history and administered tests are listed in the same stream; the history can be searched, and the whole of it can be read end to end in reading mode. Overdue session payments appear on the card as an outstanding balance. When moving to PsyAgenda, a client list can be imported at once with an Excel template, or clients added one at a time from the phone's contacts. The client card can be exported as Word or PDF.

Session notes and attachments

Every appointment has three separate note fields: notes prepared before the session, what is written during or after it, and the topics to be taken up in the next session. Each field can be opened in a full-screen reading mode. Images belonging to a session can be attached to the record, or captured directly with the device camera. A photograph of a handwritten note can be converted into digital text with optional AI support, according to a chosen handwriting style. An AI analysis can be drawn from the session notes, and a suggestion requested for the next session. If the application closes unexpectedly, an unfinished note is restored.

Psychological test modules

Offers a test section covering the common projective tests, with manual entry for anything outside that scope. The Rorschach test can be administered across ten cards, each response recorded separately. In projective drawing tests (Draw-A-Person, House-Tree-Person, Kinetic Family Drawing, Baum, Animal, School), a photograph of the drawing can be attached to the record. Every test given takes its place in the client's history in chronological order. The therapist can write their own evaluation for each test and can also obtain an AI evaluation; optionally, a single report can be produced that blends the therapist's own views with the AI's insights. A completed test can be exported as Word or PDF.

Budget and income tracking

An income record is created automatically for every session; all that remains is to mark it as collected. Sessions are listed with gross fee, discount rate and amount, and net fee; pending, overdue, and not-yet-due amounts are shown separately. For a client with an overdue payment, a payment reminder message can be prepared in a single tap. Expenses are recorded by category, with ready-made categories such as rent, bills, and supervision, and new ones can be added. Records can be filtered by client, category, date, and payment status, and frequently used filters can be saved. The analysis section shows total income, expenses, and net profit along with twelve-month income-expense and session-count charts; the full list or a filtered one can be exported to Excel.

Backup and export

Even when synchronization is not used, all data — including session images — can be backed up into a single encrypted file; encryption with AES-256 is mandatory during backup. The data can be carried offline to a new device with this file; a backup can be restored into the PsyAgenda application the user has downloaded on any other platform, regardless of where it was created. Since the password is held only by the user, forgetting it means the contents of that backup can no longer be reached. Client cards, session history, test reports, and financial breakdowns can also be exported as Word, PDF, or Excel, and the file can optionally be password-protected during export.

Optional AI

AI features are off by default and run only with the user’s own Google Gemini key; the key is stored encrypted on the device. Once enabled, a photograph of handwritten notes can be turned into digital text; insights can be drawn from session notes, Rorschach responses, or drawing tests, a suggestion can be requested for the next session, and written text can be improved. For each evaluation, the model, the analysis method, and the level of detail (summary, medium, detailed) can be chosen by the user. Since the request passes directly between the user’s device and Google, the developer sees no part of it. Requests carry only the client’s age, gender, and the relevant content; name, phone number, and email address are never sent. The AI does not diagnose; the final judgement and responsibility always rest with the therapist.

License and trial period

The application can be used free of charge with all features for 30 days. When the trial period ends, records are not deleted; the application switches to read-only mode and existing data remains viewable. Monthly and annual subscription options are offered. Purchases are made only from the License tab inside the application, through the official store of the relevant platform; there is no other purchase channel.
