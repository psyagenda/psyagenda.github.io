PsyAgenda

Smart Therapist Agenda. Ease your life.

PsyAgenda is an agenda application that digitizes the workflow of psychologists, psychiatrists, and counselors end-to-end. Client records, the appointment calendar, session notes, administered psychological tests, and income and expense tracking are all brought together in one place. The application is built on a serverless architecture; all records are stored only on the user's own device, encrypted.

iPhone iPad Android Mac Windows

The application is currently in preparation for release. Once published, it will offer exactly the same user experience on iPhone, iPad, Mac, Android, and Windows. The application will be available for download only through the Apple App Store, Google Play, and the Microsoft Store. As it is published in each store, the links above will be activated.

Overview

No servers

The application has no central server; once installed, it runs entirely locally on a single device by default. All data entered into the application is stored solely on the user's own device, in an encrypted database. No one apart from the user — not even the developer — can access this database. The user can permanently and completely delete all data entered into the application at any time.

Optional synchronization

The application can be installed on more than one device, and synchronization between them can be enabled if desired. The session notes of an appointment created on an iPhone can be written on an iPad or an Android tablet. Synchronization again runs without any intermediary server, through the user's own Google Drive account, and is encrypted at every stage. The user can also permanently and completely delete all data stored in that Drive account at any time.

Backup and export

Even when synchronization is not used, all data can be backed up into a single encrypted file and carried offline to a new device with it; encryption during backup is mandatory. Client cards, session history, test reports, and financial reports can be exported as Word, PDF, or Excel; file encryption is available during export.

Optional AI

If the user requests it, the AI can convert a photo of handwritten notes into digital text and, according to the selected approach, offer the user insights based on session notes, Rorschach responses, or drawing tests. The feature is off by default, runs only with the user's own Google Gemini key, and since the request passes directly between the user's device and Google, the developer sees no part of it.

Features

Calendar and appointments

Daily (1, 3, 5, or 7 days) and monthly calendar views are available, with a 15, 30, or 60-minute time grid and configurable working hours. An appointment record holds the client, duration, session fee, recurrence pattern, payment status, notes, and file attachments. Recurring sessions are managed as a series; appointments are moved by drag-and-drop, and conflicting time slots are blocked.

Client management

Contact details, demographic information, a per-client session fee, and notes are gathered on a single card. There is no limit on the number of clients. Session history and administered tests are listed in the same stream, and past records can be searched. Unpaid sessions are shown as outstanding balance; the client card can be exported as Word or PDF.

Psychological test modules

The Rorschach test is administered across ten cards; for each card, the client's response, the AI evaluation, and the therapist's evaluation are held in separate fields. In projective drawing tests (Draw-A-Person, House-Tree-Person, Kinetic Family Drawing, Baum, Animal, School), a photograph of the drawing is attached to the record. Printed tests administered outside the app can be entered manually. All tests can be turned into Word or PDF reports.

Session notes and attachments

Every appointment has separate note fields for pre-session, session, and next session. Files and photos can be attached to notes. A photograph of a handwritten note can be converted into text with optional AI assistance. If the application closes unexpectedly, the unfinished record is restored.

Budget and income tracking

Session fees are kept with gross, net, and discount amounts, and payment status is marked for each session. Pending, overdue, and not-yet-due amounts are displayed separately. Expenses are recorded by category, twelve-month income and expense charts are generated, and the full breakdown can be exported as an Excel file.

Notifications and reminders

A notification or alarm can be set on the phone ahead of a session, and the client's name can be hidden in the notification. The text of the WhatsApp, SMS, or email reminder sent to the client is prepared by the application, and sending is completed with the user's approval.

AI assistance (optional)

AI features are off by default and run only with the user's own Google Gemini key. They can be used for session note analysis, test evaluation, report drafting, and proofreading. Only age, gender, and the relevant content are sent in these requests; the client's name, phone number, and email address are never sent under any circumstances. The AI does not make diagnoses; the final evaluation and responsibility rest with the therapist.

Synchronization and backup

Synchronization is optional and runs through the user's own Google Drive account. Because the data is encrypted on the device before upload, neither Google nor the application's developer can decrypt the content. A password-protected backup file can also be created and restored on any device; entering an incorrect password does not delete the existing records.

Security and privacy

  • The database is always kept encrypted on the device (AES-256). The encryption key is stored in the operating system's secure key store.
  • The application is locked with a password and biometric verification. Automatic lock takes effect once the configured idle period elapses.
  • There is no need to create an account or register. At first launch only the language, an app password, and a security question to be used if that password is forgotten are set.
  • The application contains no ads, no analytics, and no user tracking.

Platforms and languages

PsyAgenda runs on iPhone, iPad, Android, Mac, and Windows. The interface is available in Turkish and English.

License and trial

The application can be used free of charge with all features for 30 days. When the trial period ends, records are not deleted; the application switches to read-only mode and existing data remains viewable. Monthly and annual subscription options are offered.
