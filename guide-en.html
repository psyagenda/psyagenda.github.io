Usage Guide

PsyAgenda is a smart agenda application that enables therapists to manage their sessions, clients, tests, and financial processes from one place.

Key Features

  • Calendar & Appointment Management: Plan your appointments easily with daily, weekly, and monthly calendar views. Recurring sessions, drag-and-drop rescheduling, and collision detection are supported.
  • Client Management: Create detailed cards for each client. Session history, notes, tests, and financial information are gathered in one place. Export client cards as Word or PDF.
  • AI-Powered Analysis: Analyze your session notes, evaluate Rorschach and drawing tests, and generate comprehensive AI reports about clients using Google Gemini API integration.
  • Test Modules: Administer and finalize Rorschach, projective drawing tests, and manual tests digitally. Download test reports as Word/PDF.
  • Budget & Financial Tracking: Manage your finances with session fees, income-expense tracking, overdue debt alerts, and financial analysis charts.
  • Notification Messages: Send appointment notifications and reminders to your clients via WhatsApp, SMS, or email.
  • Synchronization: Sync across devices via Google Drive with encrypted synchronization. All data is encrypted with AES-256; no plaintext is stored on the server.
  • Backup & Restore: Back up your data as an encrypted .thnbak file; restore anytime.
  • 100% Local Data Storage: All your data is stored only on your device. Synchronization and AI usage are entirely optional.

Getting Started

  1. Language & Currency: Select the app language and currency on first launch. You can change these later from Settings.
  2. App Lock: Set an app password to protect your data. Be sure to fill in the security question — it's the only recovery method if you forget your password.
  3. Business Name: Set your business name to appear in the home screen header from Settings > Personalization.
  4. Add a Client: Add your first client from the Clients screen. Name is required; all other fields are optional.
  5. Create an Appointment: Tap on the desired time slot in the Calendar screen to create an appointment. Select a client, set the session duration, and save.
  6. Sync (Optional): To use on multiple devices, connect your Google account from Settings > Synchronization and set a sync password.

Tips

  • During appointment creation, use "Quick Add Client" to create a new client without leaving the form.
  • Drag appointments in the calendar to reschedule them to different time slots.
  • Hide finished sessions on the home screen using the eye icon to focus on the rest of your day.
  • Client card reports include all session notes, test results, and AI evaluations for that client.
  • For AI features, enter your Google Gemini API key from Settings > API Management. Click the info icon for a detailed guide.
